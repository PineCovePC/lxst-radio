# LXST Radio

Android-first push-to-talk PWA. Original radio chrome: LCD, mesh radar, Chat tab.

**https://pinecovepc.github.io/lxst-radio/index.html**

On Android Chrome: open that URL → Add to Home screen.

If you still see the old handshake overlay, close the tab, wait a few seconds, and reopen — or Chrome menu → **Add to Home screen** again after a refresh. The service worker will drop the cached overlay build.
