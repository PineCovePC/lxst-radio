# LXST Radio

Android-first push-to-talk PWA. Original radio chrome: LCD, mesh radar, Chat tab.

**https://pinecovepc.github.io/lxst-radio/index.html**

Two phones on the **same channel** (Calling by default) find each other over a public MQTT mesh. No simulated contacts.

On Android Chrome: open that URL → Add to Home screen.

If you still see old stations or a handshake overlay, open `index.html?v=7` once so the service worker refreshes.
